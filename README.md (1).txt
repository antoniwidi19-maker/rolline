# Starter Project Web (HTML, CSS, JS)

Template proyek web sederhana yang berisi struktur dasar HTML, CSS, dan JavaScript.

## Struktur File

- `index.html` — Halaman utama aplikasi web.
- `style.css` — Styling dan tata letak halaman.
- `script.js` — Logika interaktif JavaScript.
- `README.md` — Dokumentasi proyek.

## Cara Menjalankan

1. Ekstrak file ZIP ini ke folder lokal Anda.
2. Buka file `index.html` langsung di browser (Chrome, Edge, Firefox, Safari) atau gunakan ekstensi *Live Server* di VS Code.
